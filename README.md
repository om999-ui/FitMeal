# FitMeal – Nutrition Tracker

FitMeal is a full-stack **MERN-based nutrition tracking application** that helps users log meals, track daily macros, and maintain healthy eating habits through a clean and responsive interface.

🔗 **Project Link: https://github.com/om999-ui/FitMeal

---

## 📌 Features

- User-friendly meal logging system
- Daily macro tracking (calories, protein, carbs, fats)
- Responsive UI built with Tailwind CSS
- Secure and scalable backend APIs
- Optimized database interactions for performance
- Clean separation of frontend and backend logic

---

## Tech Stack

**Frontend**
- React.js
- Tailwind CSS

**Backend**
- Node.js
- Express.js

**Database**
- MongoDB

**Version Control**
- Git & GitHub
